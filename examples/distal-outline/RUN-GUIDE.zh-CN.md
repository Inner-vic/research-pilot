# 跟着案例启动自己的研究

## 1. 打开仓库，让 Skill 引导

先完成根目录 [快速开始](../../README.md)。前提是已登录的 Codex、Python3.11+；项目入口会准备 SDK 和工作台。

在 Codex 当前项目输入 `/`，选择 **ResearchPilot**，发送：

> 我是第一次用。带我看 examples/distal-outline 这个案例，先不训练。请先说明我已经具备哪些条件，还缺什么；不要让我填内部JSON。

你应看到：任务/数据/基线的简短说明，以及下一项真正缺失的信息。若只是查看案例，流程停留在阅读，不提交训练。原作者的历史案例不会被自动登记成你的已完成研究。

## 2. 准备 LPAI 接入与初始方案

想实际运行时说：

> 我想用这个公开数据做一项新的研究，复用案例的数据版本和评价协议，目标先设验证 macro-F1 0.90。使用我自己的 LPAI 组件库，20轮起步、允许10—30轮。请先检查环境和可用资源，准备方案，暂不提交。

ResearchPilot 应先读取本机官方 LPAI Skill/SDK 和正常认证，再只补问缺失的 namespace、组件、数据挂载或资源范围；不复制作者账号、任务UID或运行路径。官方平台的认证/审批规则仍照常适用。

它会根据 [research-brief.json](research-brief.json) 准备新研究：

- 数据只取同一 TRAIN 文件，先核对公开 SHA256；不读 TEST 来调参。
- 固定协议 `sdm-distal-20261113-v1`、同一分层划分规则与种子42。应得到449/151样本，验证支持数56/95，划分摘要也应匹配。
- 初始模型输入为1通道、卷积通道16；学习率0.001、batch64、20轮。模型/训练器与平台执行的具体绑定由 Codex 准备和核验。
- 资源按你的可用性和实际授权确认；案例在远端CPU任务上运行，不需要照搬作者的宿主或假定本地执行。
- 新研究使用新的研究ID和任务身份，历史14次测量只作参考，不计入新研究成绩。

数据下载和初始配置由 Codex 使用现有 `prepare_public_ts.py`、初始化入口及已选官方 SDK 处理；你不必记内部命令或手写运行JSON。若新环境缺少评估/执行能力，应先补齐或明确阻塞，不能伪造已启动。

## 3. 确认后才提交

初始摘要应包含：任务、来源/划分、主指标与目标、模型、训练参数、组件与资源、预计耗时依据，以及未解决问题。确认无误后说：

> 按已确认的初始方案和资源范围开始，使用我的 LPAI 组件库持续迭代到验证 macro-F1 0.90；定时消息任务不用开启。

此后由唯一 SDM 后台执行：提交、监控、回收、核验、分析、审议、实施和再次提交。LPAI若返回待审批或未知提交结果，沿原请求核对，不换身份重提。

## 4. 在工作台看真实状态

后台建立研究并登记后，Codex会提供工作台链接。端口8792已被占用时，使用初始化返回的实际链接。

- 概览：目标、当前最优、最新结果、正在排队/训练/分析还是审议。
- 实验记录：有效结果、实际基线、训练参数和逐轮曲线；展开类别明细查看 P/R/F1 与混淆矩阵。
- 研究主线：当前最新任务/方案及其实际选用的上游基线。
- 研究脉络：默认方案+结果；选中方案可只展开其审议、实施和训练过程。

排队不算训练完成，进程退出也不是产物核验成功。阶段必须来自原状态和回执。等待期间可关闭网页；后台仍需电脑与网络在线，默认没有开机自动研究服务。

## 5. 让结果决定下一步

首个有效结果后，后台应自动对比目标、历史最优、类别错误和原始曲线，再提出和审议下一方案。你可以观察或指导：

> 解释当前最优与最新实验的差别，为什么决定回退、继续或修改模型？下一轮的实际基线、改动和可证伪预期是什么？

这个提问用于了解和指导，不应是模型每次接续的启动门槛。新结果差可以保留为负面证据；不用强制复刻案例14步，也不能把14轮设为预算。你的新结果不同，研究路径也可以不同。后台遇到真实外部阻塞应展示原因和唯一缺口，不空转或重复提交。

## 6. 随时暂停、恢复与完成

网页点击“暂停研究”，或在当前Codex聊天说“暂停接续，保留已提交的远端训练”。暂停后不发新的研究工作；已经提交的平台任务不因此自动停止。

需要继续时用工作台“继续研究”，沿原研究/Context/任务/Guard核对恢复；响应未知时先查原请求回执。也可以在Codex中明确要求同身份恢复。停止远端训练是另一项明确指令。

达到登记目标后应输出：最优候选、实际指标和协议、相对初始基线的变化、有效/失败尝试、剩余风险及原始证据位置。不要因达到目标再自行提高目标；若需额外TEST验收，应单独设计确认，不能把它继续当自适应调参集。

## 可选：核对教学摘要

```sh
python examples/distal-outline/verify_case.py
```

这只读取案例JSON、核对SHA256、按混淆计数重算指标和基线/候选关系；没有训练、模型调用、LPAI请求或后台进程。完整真实训练请走上面的Codex＋官方LPAI路径。
