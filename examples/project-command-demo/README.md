# 项目自有入口示例：三类二维分类，远端CPU训练

本例演示如何将当前项目接入ResearchPilot同一SDM 13步。它使用NumPy，不要求PyTorch模型工厂、`model.py`或二分类输入。不是RoadModel，不使用GPU，也不证明视觉任务的质量收益。

输入是720条二维合成坐标，分为内、中、外三圈三个类别。固定540条训练、180条验证，均来自本示例数据，无TEST使用。输出为每条固定验证样本的真实标签、预测类别、训练历史、权重及项目功能检查报告。

`model_impl.py`初始实现为线性特征，目的是提供一个明确的工程对照，不声称它是强研究基线。主要指标是三类分类混淆计数得到的均值IoU，目标0.95；不是分割或Pillar IoU。后继实现不能预编排，应由主会话根据实际结果设计，经独立评审和共同门禁后实施。

| 项目文件 | 职责 |
| --- | --- |
| `researchpilot.project.json` | 可移植项目事实、适用原契约、输入输出、评价和可改范围 |
| `model_impl.py`、`experiment.json` | 允许实施者修改的模型特征与实验参数 |
| `check_inputs.py` | 训练数据检查、14次微型拟合更新、2次接续一致性更新、初态身份；合计最多16次预检更新 |
| `train_model.py` | 项目自有NumPy训练入口，10轮训练 |
| `evaluate_model.py` | 固定验证预测、评价报告和权重位置 |
| `project_data.py` | 受保护数据/优化/评价公共函数 |
| `data.json`、`split-input.json` | 小型合成输入及确切固定划分 |
| `prepare_example.py` | 仅生成合成输入和项目说明，不训练、不推理、不提交任务 |
| `engineering_provider.py` | 可选非组件命令协议示例；仅做本地整数校验任务，不支持模型训练或远端调度 |

在Codex打开本目录，选择ResearchPilot，先要求检查输入输出、已有配置及缺少的信息。平台能力和当前用户授权须另由项目本机环境提供，示例不含作者凭据、资源池或授权文件。沿原初始化和冻结监督器运行，禁止直接本地执行训练、预检或评价入口。

若需重新生成示例，可运行`python prepare_example.py`；它只生成数据与说明。大数据项目应提供远端读取入口及身份，不照搬本例将小型数据嵌入载荷的方式。接入约定、共同门禁和实际验证范围见[通用交付说明](../../docs/GENERIC-DELIVERY.zh-CN.md)。
