# Retired custom LPAI companion

The custom `sdm-lpai` Skill, installer, binding and dedicated bridge have been
removed at the user's request. Do not install or invoke them. For the current
research, read and use the official `lpai` Skill and its permitted CLI operations;
see [required LPAI research](required-lpai-research.md).

Retain the original task identities, Guard, authorization and unknown-outcome
reconciliation. Shared transport code and historical receipts remain evidence;
they do not authorize a silent SDK fallback or qualify the new component loop.
Do not migrate active runs or remove the official installed Skill.
