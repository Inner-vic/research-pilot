# Evidence review capability

Resolve and activate installed `sdm-evidence-review`. D01 must enumerate all
planned Run/Attempt identities, terminal states, validity, deviations, and
artifact URIs/digests. D02 contains no untraced value. D03 binds the locked
analysis implementation, estimand, pairing, uncertainty, effect, multiplicity,
power, and missingness. D04 systematically indexes failures without protected
data leakage. Apply all five owned lenses and enforce reviewer/author separation.
Never infer platform metrics or accept best-run-only evidence.
