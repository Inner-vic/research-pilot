# Baseline contract

B01 defines purpose and applicability. B02 binds repository/revision/tree,
resolved config, dataset, split, calibration, evaluator, runtime image,
checkpoint, URI/digest, owner, signature, and policy version. Each B03 binds a
specific B02, every reproduction Run/Attempt, G10 tolerance, metrics, exact S13
receipts, reviewer, and terminal pass/fail. B04 binds source, replacement,
reason, effective boundary, authority, and active-dependency analysis. All
reproduction and deprecation objects are ID-keyed append-only records.
