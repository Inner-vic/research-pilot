# Experiment specification capability

Resolve and activate the installed `sdm-create-experiment-spec` Skill. E01 binds
question, hypotheses, baseline/treatments, isolated differences, frozen and
forbidden variables, data/geometry, budget/seeds, metrics/slices, exhaustive
decision/missingness rules, evidence, and governance. E03 fixes search fairness,
formal-test isolation, every trial, replayable selection, and independently
seeded confirmation. E04 enumerates all Runs. Frozen semantic changes become E06
only before affected dispatch and only when non-material; observed differences
become E07; other changes require a reciprocal successor.
