# Freeze contract

Freeze binds candidate-content digest, immutable E01 bytes, B02/B03, data,
split, calibration, evaluator, budget, approval subject, principal/key/role,
trust snapshot, current Git tag/freeze receipts, prior external anchor, workspace,
repository, operation ID, and CAS revision. Provisional and accepted events are
distinct; only `anchor.accepted` changes protocol state to frozen.
