# 版本变更

本页记录用户可感知的功能、修复和兼容性变化。当前使用方法见[使用指南](USER-GUIDE.zh-CN.md)，支持边界见[当前能力](EXECUTION.md)。

## 0.3.3

- 修复后继训练开始后上一结果的分析状态丢失，新结果返回后重新判断其分析状态，避免继承旧报告。
- 证据异常的任务继续显示为待核实，保留可独立核验的名称和范围，撤回未经核验的完成判断。
- 拦截同一研究的重复入口关联，已有冲突明确提示；失败的记录更新保留原进度。
- 修复 Windows 深目录中的任务记录操作，并统一命令入口的中文 JSON 输出编码。
- 重组产品介绍、安装、使用、接入与架构文档，集中说明支持范围，将开发过程和历史设计移至参考资料。
- 补充 SDM 规范继承、21步到13步的合并边界，以及监控、AI判断和状态控制协作的自主迭代机制。

**升级影响**：原研究保持所属固定版本与记录。任务范围记录不增加执行权限，安装更新不会恢复暂停研究。

## 0.3.2

- 入口明确区分单次评测和持续研究，单次任务交付结果与分析后正常结束。
- 工作台分别显示分析完成、结果驱动接续和当前自动推进，给出未启动、暂停及阻塞原因。
- 入口关联已登记研究后合并展示，页面自动定位所属研究。

## 0.3.1

- 入口与工作台共用后台身份和研究线程核验，区分控制器存活与研究可推进状态。
- 原调用未知或研究受阻时保留已有身份，避免重复启动。
- 研究脉络按方案与实验组织，详情保留评审、配置、执行、结果与分析。
- 修复 Windows 长路径下的固定版本和审查证据读取。

更早的开发与交付记录见[历史资料](archive/README.md)，其中的日期、验证范围和界面说明按原版本解释。
