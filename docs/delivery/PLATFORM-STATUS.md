# 执行与外部集成

ResearchPilot 的研究流程与具体平台接入分别配置。安装 Skill 准备本机入口和模型协作环境，执行仍依赖所选平台、本人权限及项目接口。

## 接入方式

| 集成 | 当前能力 | 使用条件与验证范围 |
| --- | --- | --- |
| LPAI | 官方组件提交、任务查询、状态观察与产物回收 | 已有真实分类研究链记录；各项目仍需核对账号、组件、数据与资源 |
| 项目命令驱动 | 固定驱动实现环境探测、提交、原请求查询、状态读取和产物回收 | 接口可用；具体远端任务系统需提供实现并独立验证 |
| GitLab | 产品源码管理、发布和自动检查；研究内 SCM/CI 有对应适配 | 研究内操作按项目配置的权限与范围执行，产品 CI 不代替模型项目的实验验收 |
| Jenkins | 提供任务、队列、日志与产物操作的适配代码 | 具体实例部署与真实构建尚未验收，不属于标准入门路径 |

项目接口要求见[接入指南](../GENERIC-DELIVERY.zh-CN.md)，SCM/CI 技术协议见[集成参考](../../skills/sdm-module/sdm-lifecycle/references/scm-ci.md)。

## 项目配置

选择实际执行方式，核对本人身份、资源范围、数据访问与输出位置。资源队列、组件编号等信息按所选平台准备，不是所有项目的通用必填项。

项目执行接口必须能准确关联原请求与平台任务。提交响应未知时使用原身份查询；结果回收核验所属源码、配置与任务。账号连通和单次提交成功不能代替持续研究链的验证。

## 能力边界

模型训练与评价在已授权远端环境执行。本地工程执行仅面向非机器学习检查。新平台接入、评价形式和正式工件资格需分别满足其要求，不能由产品 CI 或历史平台案例推定完成。

完整适用范围见[支持范围](../EXECUTION.md)，环境准备见[安装与更新](INSTALLATION-MODES.md)。
