# 任务范围与接续状态

单次评测与持续研究的区别在于任务完成边界。评测和训练是执行动作，不能仅凭执行过其中一项判断是否需要继续迭代。

## 任务范围

| 范围 | 典型需求 | 分析完成后的行为 |
| --- | --- | --- |
| 单次评测 | 评测指定权重并解释结果，本次不改模型 | 交付结果与分析后正常结束 |
| 持续研究 | 围绕目标改进模型，允许按结果调整并继续实验 | 在有效授权、预算和检查条件内推进后继 |

意图明确时沿用用户要求；存在歧义时先澄清范围。单次评测后新增优化需求，应建立明确的持续研究范围并引用已有报告。任务范围记录用于说明工作边界，执行仍需满足相应权限和条件。

## 工作台中的三个判断

| 状态信息 | 表达的事实 |
| --- | --- |
| 最近结果分析 | 最近已返回结果是否已有可核验分析；后继训练尚未返回结果时，保留上一结果的分析状态 |
| 结果驱动迭代 | 是否已有结果进入后继分析与方案流程；它不等于下一训练已提交 |
| 当前自动推进 | 当前后台是否处于能够继续派发工作的状态；暂停、离线或阻塞时为否 |

新结果返回后，重新判断它的分析是否完成，不沿用上一轮报告。某研究历史上已进入持续迭代，也可能当前处于暂停状态。

## 状态与处理

| 工作台状态 | 含义与处理 |
| --- | --- |
| 单次评测已完成 | 已登记结果与分析文件，任务按范围结束，无需触发下一轮 |
| 持续研究尚未启动 | 已明确研究意图，目标、执行范围、接入或控制器等前置条件仍待完成；查看具体原因 |
| 持续研究启动状态待核实 | 已关联配置，尚未核验已登记研究及其实际运行状态 |
| 已进入持续迭代 | 已记录结果驱动的后继接续，结合当前阶段查看分析、评审或执行进展 |
| 持续迭代受阻 | 证据、评审、权限或调用状态等存在未解决问题，需要按原原因处理 |
| 持续研究已暂停／已结束 | 当前不再派发新工作，依据暂停或停止记录决定后续动作 |
| 任务记录待核实 | 入口、证据或关联无法核验，保留任务显示并撤回完成判断 |

一个研究只关联一个入口范围。重复关联或证据摘要异常时，工作台显示冲突或待核实，不通过改显示状态继续执行。

任务记录只核验文件绑定，不单独证明模型质量或科学结论。运行异常见[状态与排障](CONTINUOUS-RUNTIME.zh-CN.md)；操作示例见[使用指南](USER-GUIDE.zh-CN.md)。
