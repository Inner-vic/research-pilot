# 支持范围与当前限制

本页描述当前产品能力及其验证边界。具体操作见[使用指南](USER-GUIDE.zh-CN.md)，接口要求见[项目接入](GENERIC-DELIVERY.zh-CN.md)，版本变化见[变更记录](CHANGELOG.md)。

## 当前能力

| 领域 | 已支持能力 | 使用条件 |
| --- | --- | --- |
| 任务入口 | 区分单次评测与持续研究，调查当前项目并整理方案和执行范围 | 目标和权限明确，项目事实可核对 |
| 持续研究 | 分析、方案、实施、独立评审、远端执行和结果接续 | 训练与评价接入完整，后台及服务可用，授权和预算有效 |
| 协作 | 持续研究主会话与独立评审会话，保留逐轮审议与修订 | 当前账号具有所需模型访问能力 |
| 执行 | 官方 LPAI 组件；项目命令驱动接口 | 本人平台、数据、资源及驱动经过接入核验 |
| 评价 | 规定格式的多类别分类准确率、宏平均 F1、均值 IoU；标量回归 MAE、MSE | 固定评价约定、完整逐样本结果和产物 |
| 控制与恢复 | 状态监控、暂停、继续、原任务对账和所属版本恢复 | 原记录完整，执行结果能够核实 |
| 工作台 | 实验指标、方案与实验详情、研究主线与分支图谱、接续和阻塞状态 | 当前项目的研究或任务记录已登记 |

## 验证范围

| 范围 | 已有证据 | 适用限制 |
| --- | --- | --- |
| LPAI 组件执行 | 有真实远端分类实验、监控、结果回收及原身份接续记录 | 不能据此推定任意组件和账号已经可用 |
| 通用分类研究 | 有合成数据 CPU 实验从首轮结果、模型修改、独立评审到后继提交及停止的完整记录 | 简单分类案例不代表其他任务的训练效果或泛化能力 |
| 标量回归与其他命令驱动 | 有结果契约和接口层的软件检查 | 尚不能作为第二家远端平台或回归模型完整实训验收 |
| 运行与展示 | 有多轮离线控制、恢复、状态异常和工作台验证 | 不能替代真实平台全部故障、操作系统重启和长期无人值守测试 |

真实案例和机器核验摘要收录于[参考资料](archive/README.md)。模型指标改善属于相应实验，不能直接归因为产品本身；验证集达标与科学假设得到确认也需分别解释。

## 已知限制

- **RoadModel 持续研究**：分割、Pillar 评价和大检查点回收需要专门接入与完整闭环验收；已有工程预检或独立评测不代表该链路已完成。
- **前台聊天联动**：工作台可显示已记录的来源和后台会话信息，尚未交付任意聊天切换自动跟随及完整双向跳转；前台聊天全文不自动同步到后台。
- **运行条件**：本机后台、网络和模型及平台服务需要可用。关闭网页可继续研究，关机后的自动分析、恢复与长期无人值守尚不能保证。
- **正式资格**：完整 SDM 签名、工件发布、外部账本锚定及部署资格需另行满足相应协议；普通实验记录和代码发布不自动具备这些资格。
- **旧研究升级**：安装更新不就地迁移已固定的研究版本、权限和记录。原研究按其所属版本恢复。

## 后续验证重点

优先补齐 RoadModel 的评价与持续研究验收、其他远端执行系统与回归任务的真实执行验证，以及重启和长期运行的可靠性验证。前台聊天导航与自动跟随需按宿主能力分别实现和验收。

上述事项描述当前缺口，不构成执行新实验或恢复现有研究的授权。历史开发与验收过程见[归档索引](archive/README.md)。
