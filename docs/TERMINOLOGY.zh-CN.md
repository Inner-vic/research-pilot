# 术语表

以下名称用于产品文档与工作台。历史协议字段和原始证据保留其所属版本的名称。

| 术语 | 含义 |
| --- | --- |
| ResearchPilot | 产品与 Skill 的统一名称，调用标识为 `$researchpilot` |
| SDM | 模型开发的规范与治理基础，提供契约、证据、评审、权限和决策规则 |
| BMAD ML | 项目的历史来源名称，不作为当前产品的另一名称 |
| 研究 | 围绕目标和约定范围组织的一组方案、实验、证据与决定 |
| 单次评测 | 对指定实现或权重执行评价并分析结果，完成后结束 |
| 持续研究 | 在有效范围内依据实际结果修订方案并继续实验 |
| 研究方案 | 一轮研究的依据、假设、改动、比较对象、执行计划和预期判断方法 |
| 实验 | 方案对应的配置、执行、结果与分析，失败及未完成任务同样保留记录 |
| 结果记录 | 平台执行事实、回收产物和评价结果，是实验详情的一部分 |
| 结果分析 | 对有效结果、失败或缺失证据的解释，支持下一步决定 |
| 独立评审 | 对具体方案、代码或证据的质询与复核；技术协议也称生成—质询审议 |
| 比较起点 | 当前方案实际选择的既有实现或候选，可以来自较早实验 |
| 当前最优候选 | 按约定指标和选择规则取得的最优有效结果，不自动等同正式基线 |
| 基线 | 具有明确版本、评价条件和适用依据的比较参照，复现与固定要求按研究阶段处理 |
| 研究主线 | 已选用候选组成的演进路径 |
| 研究脉络 | 所有已记录方案与实验的关系，包括候选分支和未入选结果 |
| 执行授权 | 用户与平台允许的操作及范围，方案或代码评审不能替代它 |
| 固定运行版本 | 研究开始时固定的执行代码、配置和关键指导；技术记录通常称冻结版本 |

## 状态用语

平台任务成功表示任务达到平台终态；有效结果还需要通过所属产物与评价核验。指标达标表示满足登记目标，科学结论则依据研究协议与证据单独判断。

“未实现”“缺少证据”“不适用”和“已有证据可复用”分别表达不同情况。文档与工作台应采用具体状态，不以笼统的“通过”替代这些区别。

流程职责见[研究流程](WORKFLOW-GUIDE.zh-CN.md)，接续状态见[任务范围与状态](TASK-SCOPE.zh-CN.md)。
