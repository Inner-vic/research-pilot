# 工作台与会话

ResearchPilot 包含前台对话、后台研究会话和研究工作台。三者围绕同一研究协作，各自承担不同职责。

## 职责与信息

| 位置 | 负责的工作 | 可查看的信息 |
| --- | --- | --- |
| Codex 前台对话 | 需求沟通、方案确认、解释结果和调整范围 | 用户请求、已确认约定和当前交互内容 |
| 后台研究主会话 | 结果分析、方案设计、修订和代码实施 | 所属研究的工作历史、本轮方案及实际证据 |
| 后台独立评审会话 | 只读质询方案、实际代码与证据 | 逐轮评审对象、意见、修订回应和结论 |
| 研究工作台 | 展示任务、实验、指标、关系及运行状态 | 已保存研究记录、原始报告入口和已记录会话信息 |

持续迭代由后台研究控制器组织。训练完成后，控制器核验并回收结果，继续主会话分析，再衔接评审、实施和下一轮执行。工作台不是循环的触发器，浏览器关闭后后台仍可继续。

## 研究关联

工作台通过项目目录、研究编号和已登记配置定位研究。相同仓库的不同克隆或工作树不自动视为同一运行项目；平台账号下的所有任务也不会自动汇总到当前工作台。

存在可信来源聊天身份时，入口可将其记录到新研究索引。后台会话身份由研究记录管理；工作台关联详情按已有记录展示，不根据聊天标题或目录名补造历史归属。

入口任务关联到已登记研究后，工作台合并展示并定位该研究。单次评测记录保留自己的完成边界，不能隐式取得持续研究权限。

## 可见的研究过程

研究脉络以方案和实验组织。方案详情保留多轮方案审议、代码审议与回应；实验详情保留配置、执行、结果和分析。最终通过结论不替代中间评审过程，未完成的调用也不显示为已有结论。

后台并不会将每轮工作自动追加为当前前台聊天消息。用户可在工作台跟踪过程，也可在 Codex 请求当前进度、比较结果或解释方案依据。前台聊天全文不自动同步到后台，变更研究约定需要通过有效的控制与记录路径处理。

## 当前交互边界

| 能力 | 当前行为 |
| --- | --- |
| 定位研究 | 可按当前项目和已登记研究打开工作台 |
| 查看后台协作 | 展示已记录的主会话、评审会话及工作轮次信息 |
| 暂停与继续 | 工作台将控制请求交给所属研究控制器 |
| 任意聊天自动跟随 | 尚未交付完整支持，切换聊天不保证改变独立浏览器中的研究 |
| 从网页跳转原生聊天 | 依赖宿主能力，尚未交付通用双向导航 |
| 聊天全文同步 | 当前不提供前台聊天与后台会话的全文同步 |
