# 目录与配置

ResearchPilot 源码仓库、用户 Skill 安装和模型项目运行目录分别承担开发、入口分发与研究执行职责。

## 源码仓库

| 路径 | 内容 |
| --- | --- |
| `skills/researchpilot/` | 用户 Skill 入口源码 |
| `skills/sdm-module/` | 研究流程、规范校验、协作、执行与恢复模块 |
| `scripts/` | 安装、构建、检查及维护工具 |
| `docs/` | 产品、使用、接入与技术文档 |
| `examples/` | 可分享案例、脱敏结果和示例说明 |
| `SOURCE-MANIFEST.json` | 发布源码文件及其摘要 |

用户 Skill 由源码构建为完整 `researchpilot` 目录，包含入口和所需 `references/`。产品变更在源码中维护，再通过安装工具更新用户安装。

## 模型项目

| 路径 | 内容与共享边界 |
| --- | --- |
| `researchpilot.project.json` | 可移植项目描述，可按项目约定纳入版本管理 |
| `.bmad-ml/` | 本机环境、平台能力、任务范围和研究登记；不作为用户分发配置 |
| `.runtime/` | 项目运行依赖、安装构建及固定版本等本机资源；不进入产品发布 |
| 研究存储目录 | 由所属研究配置指定，保存运行记录、请求身份、评审和结果；不随公共 Skill 分发 |
| 模型源码与数据目录 | 沿用模型项目自身约定，研究明确允许修改和受保护的范围 |

模型项目无需移动到 ResearchPilot 仓库中。为多个项目安装时，用户入口可复用，各项目的环境、权限和研究记录分别管理。

## 版本与恢复

研究使用其固定的代码、配置与证据依据。升级用户 Skill 影响后续新建研究，已有研究按所属版本核对和恢复。移动或复制目录前需检查配置中的路径与身份绑定，不能仅凭相同仓库地址认定为同一运行环境。

安装方法见[安装与更新](delivery/INSTALLATION-MODES.md)，配置职责见[项目接入](GENERIC-DELIVERY.zh-CN.md)。
